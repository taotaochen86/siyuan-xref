# 图表公式交叉引用（siyuan-xref）v1.0.8

**English**: [README_en.md](./README_en.md) ｜ 安装：思源「设置 → 集市 → 插件」搜索「图表公式交叉引用」或 `xref`

---

## 1 一句话概括

**给思源笔记补上「图、表、公式自动编号 + 交叉引用跟着编号一起变」这件事——你不用再手打编号，也不用再改一处、全篇找一遍。**

它替你做的三件事：

1. 你只写题注文字（`稻田水位示意`），编号（`图 2`）由插件按文档顺序写进去；
2. 你在正文写「见 图 2」，插件记住这是一个**指向块 ID 的活引用**，图 2 变成图 3 时引用自己跟着变；
3. 你删了、改了、撤销了，编号整体重排，引用同步刷新——不需要你记得改过哪些地方。

## 2 主要功能

### 2.1 自动编号（图 / 表 / 公式）

| 对象 | 编号写在哪 | 插件怎么维护 |
|---|---|---|
| 图 | 独立段落开头：`图 2 稻田水位示意` | 重写段首编号，正文文字不动 |
| 表 | 独立段落开头：`表 1-1 试验设计` | 同上 |
| 公式 | 公式内部 `\tag{2}` | 只替换 `data-content` 里的 `\tag{…}`，正文公式不过 Lute、不重建块 |

- **两种编号模式**：全文连续（图 1、图 2、图 3）／按章编号（以文档最浅的标题级别换章，图 1-1、图 2-1）。
- **标签可换**：默认「图 / 表 / 式」，可改成 `Figure / Table / Eq` 等任意文字，编号逻辑不变。
- **自动触发**：停手约 1.5 秒进入判定，索引就绪后一般在 1～3 秒内落笔，全程不弹窗。
- **手动触发**：`Ctrl+Alt+N` 或 `/xrefnum`，任何时候都能立刻整篇重排。

### 2.2 交叉引用自动跟随

- `/xref`（或 `Ctrl+Alt+R`）弹出本文档的图 / 表 / 式清单，可输入编号或题注文字搜索，↑↓ 选择、回车插入。
- 插入的是**块引用** `((块ID "图 2"))`，不是普通文字——所以它能点击跳转、能被思源的反向链接统计。
- 重排时如果锚文本里的编号过期，插件把 `((块ID "图 2"))` 里的「图 2」改成「图 3」，目标块不变。
- 同一段里有多条引用、有多层嵌套，都能一并刷新；别的文档里的引用不会被动到（只处理本文档）。

### 2.3 右键一键设 / 取消题注（1.0.3 新增，1.0.6 补齐入口）

不用记 `custom-xref="fig"` 这种属性，右键段落 → 块菜单里直接点：

| 菜单项 | 出现条件 | 作用 |
|---|---|---|
| 设为图题注 | 段落块 | 写 `custom-xref="fig"`，立刻编号成「图 N」，同时居中 + 加浅底色 |
| 设为表题注 | 段落块 | 同上，编号成「表 N」 |
| 取消图表题注 | 段落**已经是**题注（有属性，或正文以「图 N」开头） | 清属性、清块名、去底色、摘掉段首编号，后面的编号自动顺延 |

- **立刻生效**：右键路径走快通道（实测 620 ms 出号），不等 SQL 索引；文字识别路径才需要等 1～3 秒。
- **支持多选**：一次选中若干段落，一起设成图题注或表题注。
- **「插入交叉引用…」在正文文字右键里**：光标停在段落、标题、列表项的文字上右键，菜单顶部就有这一项，插在**当前光标处**（和 `/xref`、`Ctrl+Alt+R` 完全等价，见 [6.3](#63-块右键菜单) / [7.5](#75-插入交叉引用)）。表格单元格里的文字同样有——那里永远不会有题注，而「见表 1 可知」这类引用恰恰写在单元格里。**块标（块左侧小图标）菜单里不给**：引用是写到文字中间的动作，挂在块标上既是多余入口又把菜单撑长；图片 / 表格本身也不给（那里该先有题注）。
- **不会叠加**：段落本来就以「图 3」开头时再点「设为图题注」，是替换旧前缀，不会变成「图 4 图 3 …」。
- **取消要说得清**：正在自动重排时点「取消」，不再弹一句「请稍候再试」就结束，而是排队等这一轮收工后照做；取消后 30 秒内自动轮也不会把编号写回来（1.0.4 修复）。
- 菜单被思源强制放在 **「插件 ›」子菜单**里（原因见 [3.10](#310-插件菜单被强制塞进插件--子菜单)），点开「插件」就能看到。

### 2.4 图片 / 表格：在正确的位置插题注

图和表**自己不能当题注块**——往图片块里写编号会得到 `图 1 ![图](…)` 这种坏文本，往表格块里写会直接毁掉表格结构。所以右键图片 / 表格时给的是「在它旁边新建题注段落」：

| 右键对象 | 菜单项 | 题注落在哪 |
|---|---|---|
| 图片 | 在下方添加图题注 | 图片**下方**新建空段落（图题在下，排版惯例） |
| 表格 | 在上方添加表题注 | 表格**上方**新建空段落（表题在上） |
| 图片 / 表格 | 把下方（上方）段落设为图（表）题注 | 旁边已经是普通文字，就地转成题注，不新建块 |
| 图片 / 表格 | 取消图表题注 | 旁边已经是题注时出现，一次清干净 |

- **表格单元格内部一律不出现**任何题注菜单（含单元格里的图片）。往单元格里写编号会把表格搞坏，插件在入口就拦住，只给一条灰字提示。
- 公式块、代码块、列表块也拦住，灰字会说明原因（「公式块会自动编号，不用设题注」等），不会让你以为插件坏了。

### 2.5 撤销 / 重做 / 误删重建

- **为什么不用 Ctrl+Z**：插件写块走 `/api/block/updateBlock`，思源的撤销栈只记编辑器自己发起的操作，**API 写入根本不入栈**（见 [3.5](#35-思源的-ctrlz-撤不到-api-写入)）。所以插件自带一套撤销栈。
- `Ctrl+Alt+Z` 退一轮、`Ctrl+Alt+Y` 再进一轮；默认保留 **10 轮**（设置里可改 1~50），存 `undo-stack.json`，**关掉思源再开也能撤**。
- **删掉的块能按原 ID 重建**：思源 `insertBlock` 会保留 DOM 里写死的 `data-node-id`（1.0.2 实测），所以误删图 / 表 / 公式后按 `Ctrl+Alt+Z`，块以**完全相同的 ID** 回来，指向它的 `((块ID "图 2"))` 自动接回、点得动。

### 2.6 失效引用治理（1.0.2 起默认「不动手」）

| 模式 | 行为 |
|---|---|
| 不处理，保持原样（**默认**） | 引用一个字都不改，也不涂红。删错了按 `Ctrl+Alt+Z` 把块重建回来即可 |
| 仅标红，保留引用 | 正文里给死链加红色删除线样式做提醒，引用本身不变 |
| 转成红色删除线文本（不可逆） | 把 `((块ID "图 2"))` 烧成纯文字「图 2」，**先等 10 秒**，10 秒内撤销能救回 |

- 「指向已取消题注的块的引用」也按同一套规则处理——取消题注后，引用它的地方自动进入失效判定，不会留一堆指向普通段落的假引用。
- 判定**不依赖状态表**，靠数据现算：把题注重新设回去，红标自动消失，历史残留也一并纠正。
- 以前被「转成文本」烧掉的引用，设置里点「还原当前文档」按钮能改回 `((块ID "锚"))`（目标块已删的自动跳过）。

### 2.7 题注排版

- **居中**：图 / 表题注段落自动设 `text-align: center`（公式块本身居中，不另设）。可关。
- **底色**：给题注加一层很淡的半透明底色，暗色主题下也不压字。四档：无 / 极浅 / 浅（默认）/ 浅蓝。自己设过底色的不会被强改。
- **取消题注时会去掉插件加的那层底色**，但**保留居中**（可能是你自己设的，而且图↔表换类型时还要用）。

### 2.8 长文档与稳定性

- 348 块的真实文档实测：一次采集 **2 次往返 / 约 0.33 秒**（旧做法 349 次往返 / 1.5 秒）。
- SQL 查询一律 `limit -1`，不会被思源默认的 64 行静默截断。
- 自动轮与手动轮互斥（`_running`），不会同时写同一个块。
- 全局网络探针**默认不装**，只在「诊断日志」打开时装（长期挂着会拖慢整个思源）。

### 2.9 界面中英双语（自动跟随思源）

- 插件不设语言开关，直接跟思源的「设置 → 外观 → 语言」走：思源是中文，插件就全中文；思源是英文（或其他语言），插件就全英文。
- 覆盖范围：右键菜单、全部提示消息、设置面板的标题与说明、下拉选项、斜杠命令、命令名、交叉引用选择面板（包括面板里的筛选按钮 `All / Figure / Table / Eq` 和章节下拉的 `All sections`）。
- 编号标签也跟着变：英文界面下新建的题注默认是 `Figure 1` / `Table 1` / `Eq 1`，中文界面下是「图 1」「表 1」「式 1」。设置里自己填过标签的**一律用你的**，不会被语言覆盖。
- 两种语言的编号前缀都认：英文界面下打开一份中文老文档，「图 3 …」照样参与编号，反之亦然。

### 2.10 引用面板按类型 / 章节筛选（1.0.8 新增）

- 面板顶部一排类型按钮 **全部 / 图 / 表 / 式**，每个带当前条数；点一下只看这一类，再点一下回到全部。
- 右边下拉按 H1 / H2 缩进列出本文档大纲，选一章只看这一节，**子节一起算进来**；只列「真的有图 / 表 / 式」的标题。
- 类型、章节、搜索词三者**叠加**：几十上百条图表公式时，先点「表」再选第 3 章，再从两三条里挑。
- 键盘习惯不变：`↑↓` 选、`Enter` 插、`Esc` 关；按钮用鼠标点，不给它们抢焦点。

## 3 破解了思源笔记的哪些问题

这一节是这个插件存在的理由。每一条都是实测出来的，不是猜的。

### 3.1 引用锚文本是写死的字符串

思源**不维护引用文字**：`((id "图 2"))` 里的「图 2」是插入当时写死的静态字符串，改目标块的 `name` 不会让已有引用跟着变，跨文档、跨设备、导出时都不变。于是「图 2」被别人插到前面变成「图 3」之后，正文里那些「图 2」就成了孤儿，和新编号撞车，读起来像重复。

→ **插件做的事**：重排编号的同时，用 SQL 找出所有指向这些块的引用，逐条改写锚文本，让引用文字永远等于块的最新编号。这是本插件的核心价值。

### 3.2 `blocks` 表索引延迟 0.6～2 秒（偶发更久）

`updateBlock` 写完，SQL 要 0.6～2 秒才能查到；刚插入的新块甚至还没进表。任何「刚改完就读、读了就决定写什么」的逻辑都会算错。

→ **插件做的事**：不凭 SQL 快照做决定。用页面上 `protyle.wysiwyg.element` 的一级子块 id 当 ground truth 校验快照，缺块就等几轮重采；右键设题注这条路径干脆绕开索引，改用 `getBlockAttrs` 实时确认属性已落地（实测 ≈0 ms），确认后立即重排。**所以右键设题注是 620 ms，而文字识别路径要等 1～3 秒**——这是刻意设计的差别。

### 3.3 删块后 SQL 仍有 2～4 秒残影

`blocks` 表在块被删除后还会保留 2～4 秒。靠它判断「目标块还在不在」，就会出现：刚删完永远报「没有失效引用」，等一会儿又突然报一堆；更糟的是残影块还占着编号位，让编号跳号。

→ **插件做的事**：判活改用实时接口 `/api/block/checkBlockExist`（实测删后 **0 ms** 就返回 `false`），退路是 `getBlockDOM`（错误信息含 `block not found`），SQL 只作最后兜底；判不出来时返回 `null`、一律按「活着」处理（**宁漏报不误杀**，误杀会烧掉用户内容）。采集结果里带 `stale` 标记的残影块，会先用实时接口核实再剔除。

### 3.4 SQL 默认只回 64 行，超了静默截断

思源的 `/api/query/sql` 默认只返回 64 行，超出的部分不报错、直接截断（`truncated: true`）。旧做法因此漏编长文档后半篇的所有图注，而且毫无提示。

→ **插件做的事**：所有语句显式写 `limit -1`，实测 348 块全量返回。

### 3.5 思源的 Ctrl+Z 撤不到 API 写入

思源撤销栈只记录编辑器自己发起的编辑动作。插件改块走 HTTP 接口，写完**不入栈**——所以按 `Ctrl+Z` 只会撤掉你刚敲的字，撤不到插件的改动。这不是 bug，是架构差异，也是旧版「按了没反应」的真正原因。

→ **插件做的事**：自建撤销栈，记录每轮改了哪些块、每块改前改后的 DOM、以及 `name` / `custom-xref` / `style` 三个属性的旧值，落盘跨重启保留。

### 3.6 `markdown` 模式写块会清空块属性

块的属性（`name` / `style` / `custom-xref` / 你自己加的 `memo`、颜色…）全部挂在块根节点的 HTML 属性上。`updateBlock` 用 `dataType: "markdown"` 会**拿 markdown 重建整块，把根节点属性全部丢掉**。

→ **插件做的事**：一律用 `dataType: "dom"` 整块回传——先取当前块 DOM（带着全部属性），把新内容搬进旧根节点，根节点原样保留再写回（细节见 [9.1](#91-为什么必须用-dom-模式写块)）。

### 3.7 公式正文在 `data-content` 上，重建块就丢

公式的正文存在块根节点的 `data-content` 属性里，**不在子节点里**。任何「取 HTML → 重排 → 写回」的常规做法都会把公式正文弄丢，或者变成一个只剩编号的空块。

→ **插件做的事**：公式走专用路径，只把 `data-content` 里的 `\tag{…}` 换掉再原样写回，**不经过 Lute、不重建块、不碰子节点**。另加三道保险：空公式不编号、公式编辑器有焦点时整轮跳过、写回前比对长度（缩水四成以上判定为采集到半截，放弃写入）。

### 3.8 表格块塞不进编号

表格块内部是 `NodeTable` 结构，往里写编号会破坏表格。思源原生的「图片题注」也只覆盖图片，表格没有对应机制。

→ **插件做的事**：表格题注一律由**独立的相邻段落**承载（表题在上方）。这样题注段落可以居中、可以有底色、可以带双链、可以加文本样式，导出时也是正常文字。

### 3.9 单引号锚文本导出时会炸开

`((块ID '图 2'))`（单引号）是「动态锚文本」，导出成 Word / PDF 时会被替换成**目标块的全文**——公式引用会瞬间变成一大串 LaTeX 源码。

→ **插件做的事**：插入引用时统一用**双引号**写静态锚文本，并在文档里明确约定这一条（见 [5.5](#55-三条写作约定照做才不会乱)）。

### 3.10 插件菜单被强制塞进「插件 ›」子菜单

思源 App 层在 emit `click-blockicon` / `open-menu-content` 之前，会先用一个新的 `subMenu` 顶替 `detail.menu`，事件跑完再把这个 subMenu 整体挂成主菜单最底部的「插件 ›」项。也就是说**凡经 `detail.menu.addItem` 加的项注定进子菜单**，调 `index`、加分隔线、事后搬 DOM 全部无效（搬走还会破坏 MenuItem 宿主，点完菜单不关闭）。

→ **插件做的事**：不和 App 层硬拼，直接拿主菜单实例（`window.siyuan.menus.menu`）在根层加项，并把它提到菜单顶部。所以你看到的是：右键 → 菜单**最上面**就是「设为图题注 / 设为表题注」，点完立即关闭。这是 3.8.9 上试出来的可行路径（读完 `common.*.js` 才确定的）。

## 4 现有思源插件与原生能力的优缺点

### 4.1 思源原生机制

| 能力 | 优点 | 局限 |
|---|---|---|
| 图片题注（图片块自带的说明文字） | 原生、零配置、图片随题注走 | **只覆盖图片**；表格、公式没有对应机制；题注文字里放不了块引用和双链；导出格式不可控 |
| 块引用 `((id "锚"))` | 双向链接、可点击跳转、反向链接能统计 | 锚文本是**静态字符串**，目标块编号变了不会自动跟随（3.1）；用单引号则导出炸开（3.9） |
| 文档内 SQL / API | 能力强、可编程 | 有索引延迟、64 行截断、删块残影，直接用很容易算错（3.2～3.4） |
| 思源 Ctrl+Z | 覆盖编辑器内的操作 | **覆盖不到插件 / API 写入**（3.5） |

**结论**：思源把「块级引用」的地基打得很好，但**没有把它延伸到「论文式编号」这个场景**——编号要连续、要跨轮次稳定、要改一处全篇跟随，这三件事原生都不管。

### 4.2 集市里的文档样式 / 交叉引用类插件

集市上已有成熟的「文档样式 / 排版增强」类插件（例如 `document-styler` 专业文档样式拓展插件，其公开说明中包含标题自动编号与图片表格交叉引用），它们的思路与本插件不同：

| 维度 | 样式增强类插件（同类方案） | 本插件 siyuan-xref |
|---|---|---|
| 切入点 | 以 **CSS / 样式 + 结构约定**为主，一个插件打包排版、标题编号、题注、交叉引用多件事 | 只做**编号与引用**这一件事，做到底 |
| 结构要求 | 通常要求图表与题注组成**超级块**才纳入范围（避免误识别） | 不要求超级块，用**块属性 + 相邻段落**识别，原有排版不必改动 |
| 编号写入 | 多为展示层编号（样式渲染出来） | **写进正文与 `\tag`**，是真实文字，导出 Word / PDF、复制粘贴都带着编号 |
| 更新时机 | 视实现而定，公开说明中也提到过「有时更新不及时」 | 停手后自动轮 + 手动轮 + 右键快通道；每条放弃路径都写日志并挂重试 |
| 撤销 | 一般无（思源原生也撤不到 API 写入） | 自带 10 轮撤销栈，**能按原 ID 重建被删块** |
| 题注位置 | 由结构决定 | 图题在下、表题在上，符合学术排版惯例；单元格内自动禁用 |
| 代价 | 一站式，装一个插件解决多件事 | **只管编号引用**，标题编号、字体样式等要靠别的插件；题注必须是独立段落 |

**本插件的位置**：如果你要的是「一份论文 / 报告，图 1、表 1、式 (1) 全文一致，正文引用跟着变，导出后编号还在」——这是它唯一的目标。如果你要的是整套排版样式、标题自动编号，它不是替代品，建议与样式类插件搭配使用。

### 4.3 本插件的优点与代价

**优点**

1. 编号是**真实文字**，不依赖 CSS 渲染——导出、复制、被别的工具读取时都在。
2. 引用是**块引用**，可点击、可反链；锚文本自动同步。
3. 对**已有文档**零改造：不给图加超级块，不改你的排版，靠属性 + 相邻段落识别。
4. **删错了能救**：撤销栈 + 按原 ID 重建，指向它的引用自动接回。
5. 所有失败路径都留痕（`err-log.json` 里的 `giveup:<原因>`），不会静默失效。

**代价**

1. 题注必须是**独立段落**（表格块内部放不下编号，见 [3.8](#38-表格块塞不进编号)）。
2. 插件写块会产生**块历史记录**（可在文档历史里回滚）。
3. 撤销只覆盖「插件碰过的块」，其间你手改过的内容会被一起带回旧值。
4. 需要遵守三条写作约定（[5.5](#55-三条写作约定照做才不会乱)），否则编号会乱。

| 诊断日志 | 关 | **只在排查问题时开**。开启后拦截全局网络请求并写 `ws-log.json`，长期开会拖慢思源 |

### 5.5 三条写作约定（照做才不会乱）

1. **题注写成独立段落**：`图 2 稻田水位示意`。表格块内部塞不进编号。重排时会顺手把这行设为居中 + 浅底色。
2. **公式编号写进 `\tag`**：`$$ … \tag{2} $$`，插件自动维护；空公式不编号。
3. **引用用双引号**：`((块ID "图 2"))`。不要用单引号——单引号是动态锚文本，导出 Word / PDF 时会展开成块全文（公式会变成一大串 LaTeX），见 [3.9](#39-单引号锚文本导出时会炸开)。

## 6 触发词与快捷键

### 6.1 斜杠触发词

在编辑器里输入 `/` 后输入任一词：

| 触发词（任选其一） | 作用 |
|---|---|
| `/xref` `/交叉引用` `/图ref` `/tref` | 弹出本文档的图 / 表 / 式清单，搜索 → ↑↓ → 回车插入引用 |
| `/xrefnum` `/重排编号` `/图表编号` | 立刻重排当前文档全部编号并刷新引用 |

### 6.2 快捷键

| 动作 | 默认键 | 备注 |
|---|---|---|
| 插入交叉引用 | `Ctrl+Alt+R` | 与 `/xref` 等价 |
| 重排图表编号 | `Ctrl+Alt+N` | 与 `/xrefnum` 等价 |
| 撤销上次重排 | `Ctrl+Alt+Z` | 插件自建撤销栈（思源 `Ctrl+Z` 撤不到 API 写入） |
| 重做重排 | `Ctrl+Alt+Y` | 与撤销配对 |

- 四个键都能在**插件设置 → 自定义快捷键**里重录，录完立刻生效并写进 `settings.json`。
- 同样的动作也注册成了**原生命令**，会出现在「设置 → 快捷键 → 插件 → 图表公式交叉引用」里，习惯统一键位管理的可以在那里设；两处设了同一个键也只会执行一次（400 ms 去重）。

### 6.3 块右键菜单

右键段落 / 图片 / 表格 → 菜单最上方：

| 右键对象 | 菜单项 |
|---|---|
| 普通段落 / 标题 / 列表项的文字 | 设为图题注 ／ 设为表题注 ／ **插入交叉引用…** |
| 已经是题注的段落 | 上面两项 + 取消图表题注 + **插入交叉引用…** |
| 图片 | 在下方添加图题注 ／ 把下方段落设为图题注 ／ 取消图表题注 |
| 表格 | 在上方添加表题注 ／ 把上方段落设为表题注 ／ 取消图表题注 |
| 表格单元格内部的**文字** | 只有 **插入交叉引用…**（单元格里不会有题注，但引用常写在单元格里），插在当前光标处 |
| 块标（块左侧小图标） | 只有题注项，没有「插入交叉引用」 |
| 表格单元格内部的**图片** | 不出现菜单，灰字提示「图表题注：表格单元格内不支持…」 |
| 公式块 / 代码块 | 不出现菜单，灰字提示「公式块会自动编号，不用设题注」 |

> 三条入口完全等价，插的都是**光标处**：正文文字上右键 →「插入交叉引用…」、`/xref`、`Ctrl+Alt+R`。区别只在**块标菜单里不给**——引用是写文字中间的动作，挂在块标上多余；图片 / 表格本身也不给，那里该先有题注。

### 6.4 快捷键的注意事项

- 组合键**必须带 Ctrl / Alt / ⌘**（单键容易被打字误触发，插件直接不录）。
- 输入框、搜索框、设置面板、引用选择面板里不响应，不会抢你输入。
- 中文输入法组字过程中不响应。
- `Ctrl+Alt+Z` 与部分编辑器的「撤销」相同——思源的撤销是 `Ctrl+Z`，不冲突；如果你装了其它也占用 `Ctrl+Alt+Z` 的插件，到设置里改掉其中一个即可。

## 7 用法与详细操作步骤

### 7.1 安装与启用

1. 思源「设置 → 集市 → 插件」，搜索「图表公式交叉引用」或 `xref`，点安装。
2. 装完在「设置 → 集市 → 已下载」里确认 **siyuan-xref 已开启**。
3. 打开任意文档，输入 `/xref`，能看到「交叉引用」选项即为加载成功。
4. 如果菜单没出现：先关一下插件再打开；仍不行就看 `data/storage/petal/siyuan-xref/` 里的 `load-check.json` 与 `err-log.json`。

> ⚠️ 更新插件后如果行为没变，请在「设置 → 集市 → 已下载」把 siyuan-xref **关一下再打开**。思源的启用接口在部分环境下会返回成功但前端不重载，这是最快的确诊手段。

### 7.2 给图片加题注（推荐路径）

1. 右键图片 → 菜单最上方点 **「在下方添加图题注」**。
2. 图片下方出现一个空段落，点进去（或光标已自动落在那里）。
3. 只输入题注文字，**不要自己打「图 1」**，例如：`稻田水位示意`。
4. 停手约 1.5～3 秒，插件写成 `图 1 稻田水位示意`，并居中 + 加浅底色。

> 想复用图片旁边已写好的文字：右键图片 → 「把下方段落设为图题注」，直接转成题注，不新建块。

### 7.3 给表格加题注

1. 右键表格 → 点 **「在上方添加表题注」**。
2. 表格上方出现空段落，输入题注文字（同样不要自己打「表 1」）。
3. 停手后自动变成 `表 1 试验设计`，居中 + 浅底色。

> 表题在上、图题在下，是学术排版惯例；插件把这个位置差写死了，不用记。

### 7.4 给公式编号

1. 插入公式块，写公式体：`y = A \sin(x)`。
2. 编号写进 `\tag`：`\tag{1}`（缺失时插件会补）。
3. 公式块**不需要题注段落**，编号由 `\tag` 承载；正文写「式 N …」不参与编号（避免重复计数）。
4. 空公式不编号——这是保护，防止生成「只剩编号」的坏块。

### 7.5 插入交叉引用

1. 光标移到要写引用的位置。正文文字上右键，菜单顶部就有「插入交叉引用…」；**表格里也一样**——单元格内的文字上右键，那里只给这一项（单元格里不会有题注）。也可以输入 `/xref` 回车，或按 `Ctrl+Alt+R`。
2. **先筛选，再挑**（图表公式多时省事）：面板顶部一排类型按钮 **全部 / 图 / 表 / 式**，每个都带当前条数，点一下只看这一类，再点一下回到全部；右边的下拉按 H1 / H2 缩进列出本文档大纲，选一章就只看这一节（**子节一起算进来**），下拉里只列「真的有图 / 表 / 式」的标题。
3. 需要时再输入编号或题注关键词继续过滤（例如 `2` 或 `水位`）。**筛选、章节、搜索三者叠加**：先点「表」再选第 3 章，剩下的通常就两三条。公式行直接显示**渲染好的公式**，不是 `$$ y=1-sin(x) \tag{2-1} $$` 这种源码（渲染器用思源自带的 MathJax / KaTeX，取不到才退回等宽源码）。
4. ↑↓ 选择，回车插入；`Esc` 关闭。
5. 插入结果是 `((块ID "图 2"))`，显示为可点击的「图 2」。

### 7.6 取消题注

1. 右键那个题注段落（或它对应的图片 / 表格）→ **「取消图表题注」**。
2. 插件依次：清 `custom-xref` → 清块名（只在是「图 N」这种自动名时才清，你自己起的名字不动）→ 去掉插件加的底色 → 摘掉段首编号。
3. 后面的编号整体前移；正文里指向它的引用按「失效引用怎么处理」的设定处理（默认保持原样）。

> 顺序很关键：必须先清属性再剥前缀。反过来做，回写 DOM 时属性会被带回来，编号剥了属性还在。

### 7.7 误删图 / 表 / 公式后救回来

1. 别急着改别的东西。
2. 按 `Ctrl+Alt+Z`（插件撤销）。
3. 被删的块以**原 ID** 重建，`name` / `custom-xref` / 居中 / 底色一并补回，正文里的引用立刻接上。
4. 重建位置在**原父块末尾**，同一容器内可能需要手动拖回原位。

### 7.8 按章编号（图 1-1）

1. 设置 → 编号模式 → **按章编号**。
2. 插件按文档**最浅的标题级别**换章：文档里只有 `##`，就在 `##` 处换章；同时有 `#` 和 `##`，就在 `#` 处换章。
3. 已有的「图 1」会在下一轮重排时变成「图 1-1」，引用同步刷新。

### 7.9 改成英文标签（Figure / Table / Eq）

1. 设置 → 「图 / 表 / 式 标签」，三格分别填 `Figure` / `Table` / `Eq`。
2. 下一轮重排会把正文前缀与引用锚文本一起换成英文。
3. 已有题注不需要重设，插件是按「标签 + 数字」模式识别的。

### 7.10 完全手动模式

1. 设置里关掉「自动重排」。
2. 需要时按 `Ctrl+Alt+N` 或 `/xrefnum`。
3. 手动轮同样受保护窗口约束（正在敲公式 / 代码时会提示稍后再试），不会写坏正在编辑的块。

### 7.11 从旧版本升级

- 1.0.1 → 1.0.2：默认「失效引用怎么处理」从「转成文本」改成「不处理」，插件会**自动迁移一次**你之前没改过的设置；已烧掉的引用用「还原当前文档」按钮救回。
- 1.0.2 → 1.0.3：新增图 / 表右键添加题注与「文字自动识别」开关，无需任何迁移。
- 1.0.5 → 1.0.6：正文文字上右键也能插交叉引用；界面中英双语（跟随思源语言）。旧文档不动，无需迁移。
- 1.0.6 → 1.0.7：交叉引用面板里公式渲染成公式本身，不再显示 LaTeX 源码。无需迁移。
- 1.0.7 → 1.0.8：面板顶部新增「类型 + 所属标题」筛选。无需迁移，编号规则一字未动。
- 升级后行为没变化 → 手动关开插件一次（见 [7.1](#71-安装与启用)）。

## 8 现有不足

诚实列出，别指望它做不到的事。

### 8.1 功能边界

1. **只处理当前打开的文档**，不跨文档。跨文档编号一致性（例如「全书图 1-1」）不在范围内。
2. **题注必须是独立段落**。表格块内部嵌不下编号；思源原生的图片题注（图片块自带说明文字）也不参与本插件的编号。
3. **只认 `\tag`**。手工在公式里写别的编号形式（如 `\qquad (1)`）不会被识别或维护。
4. **不支持子图 / 子表编号**（图 1(a)、图 1(b)），也不支持自动生成图表目录。
5. **筛选依赖标题块**。章节下拉只列带 `h1`~`h6` 的标题；整篇没有标题（单节文档 / 纯图片集）时下拉自动隐藏，只剩类型筛选和搜索。

### 8.2 已知风险与注意事项

1. **撤销只回滚插件碰过的块**。其间你手动改过同一块，撤销会把你的改动一起带回旧值——注意时机。
2. **从没参与过重排的块被删，插件撤销栈里没有它**，救不回来（用思源自己的 `Ctrl+Z`）。
3. **重建的块落在原父块末尾**，同一容器内可能需要手动拖回原位。
4. **光标停在待改的块里时会一直等**，所以「边写边看编号不变」是正常的，移开光标即生效。
5. **重排会改写块内容**，块历史里会多出若干条记录（可在文档历史回滚）。
6. **「转成文本」模式不可逆**。烧掉之后块 ID 就没了，只能用「还原当前文档」按钮按日志救回（目标块必须还在）。
7. **文字识别会误伤**。正文顺口写「图 3 中可以看出…」的普通段落会被当成题注。两个解法：右键确认题意后保留、或直接关掉「文字自动识别」只认属性。
8. **菜单在「插件 ›」子菜单里**（思源 App 层的硬限制，见 [3.10](#310-插件菜单被强制塞进插件--子菜单)）。插件已尽力把项提到菜单顶部，但无法完全绕开分组。
9. **移动端**：自动编号与手动重排可用；右键块菜单在移动端表现以思源自身为准，可能不出现。

### 8.3 排查与日志

`工作空间/data/storage/petal/siyuan-xref/` 下：

| 现象 | 看哪个文件 |
|---|---|

## 9 技术实现（附录）

### 9.1 为什么必须用 DOM 模式写块

```
旧: <div data-node-id="A" name="图 1" style="text-align:center;"> … </div>
新: <div data-node-id="?" data-type="NodeParagraph"> 图 2 … </div>
        ↓ 只搬内容节点，根节点沿用旧的
写回: <div data-node-id="A" name="图 1" style="text-align:center;"> 图 2 … </div>
```

`markdown` 模式会拿 markdown 重建整块、丢掉根节点属性；`dom` 模式则原样保留。拿不到 Lute 时才退回 markdown 模式，并在写完后统一补属性。改属性（`custom-xref` / `name` / `style`）必须在 `updateBlock(dom)` **之前**做，否则会被回写的 DOM 覆盖（而且落地更晚）。

### 9.2 公式专用路径与三道保险

1. 取回该块当前 DOM；
2. 只替换 `data-content` 里的 `\tag{…}`；
3. 原样写回——**不经过 Lute、不重建块、不碰子节点**。

三道保险：空公式不编号；公式编辑器（可见且聚焦的 `.cm-editor`）有焦点时整轮跳过；新内容比旧内容短掉四成以上则放弃写入。

> 顺带一个坑：`.protyle-math` 这个类在思源里**不存在**（3.8.9 全量检索 0 处）。判断「是否正在编辑公式 / 代码」只能用「可见且聚焦的 CodeMirror 编辑器」——正文 WYSIWYG 不是 CodeMirror。

### 9.3 采集性能

| 项 | 旧做法 | 现在 |
|---|---|---|
| 块清单 | 逐块 `getChildBlocks` 递归：348 块需 349 次往返 / 约 1.5 秒 | 1 次 SQL + 1 次 `getDoc` 定顺序：**2 次往返 / 约 0.33 秒** |
| 行数 | SQL 默认 64 行静默截断 | 一律 `limit -1` |
| 顺序依据 | 递归遍历 | HTML 里 `data-node-id` 的出现顺序（DFS 先序）；已用 68 篇真实文档（2~348 块）与递归结果逐一比对，顺序完全一致 |

### 9.4 自动触发的三道保护

1. **光标所在块**：只有该块在 `EDIT_GRACE`（3 秒）内刚被改过才等；光标只是停在那儿不阻塞。
2. **自己写入的静默窗口**：插件写完后开 2.5～12 秒静默窗口，不会自激。
3. **整体一致性**：只要有一个待改块在保护窗口内，**整轮推迟**（不能「跳过保护块、其余照写」，否则出现重复编号），并挂最多 4 次重试；每次放弃都写 `giveup:<原因>` 到 `err-log.json`。

## 10 构建与发布（开发者）

### 10.1 发版前必须改的字段

| 项 | 位置 | 说明 |
|---|---|---|
| `version` | `plugin.json` **和** `package.json` | 两处都要改，只改一处会被 `preflight` 拦下 |
| `url` | `plugin.json` | 必须是真实仓库地址，**不能留 `OWNER` 占位符** |
| `description` | `plugin.json` 的 `default` 与 `zh-CN` | 把本次新增能力写进去，两种语言同步 |
| `displayName` / `keywords` | `plugin.json` | 有新功能就补关键词 |
| `readme` 指向 | `README.md` / `README_en.md` | 集市会把它们当详情页正文渲染 |
| `minAppVersion` | `plugin.json` | 必须是思源真实存在的版本号 |

`url` 尤其关键：集市详情页的**包名链接取 `repoURL`，作者链接取 `repoURL` 里的 owner**，`author` 字段只负责显示文字、不参与链接。写成 `OWNER` 会让两个链接同时 404。

### 10.2 发版步骤

```bash
bash scripts/preflight.sh                                # 体检：占位符 / url / 版本 / zip 结构
git add -A && git commit -m "release: vX.Y.Z" && git push origin main
GH_TOKEN=ghp_xxx bash scripts/release.sh [发布说明.md]    # 内部会再跑一次 preflight
bash scripts/deploy.sh                                   # 本地重装验证
```

其他命令：`npm run check`（语法 + 清单校验）、`npm run build`（生成 `package.zip`，文件在 zip 根层不套目录）。

集市只认 GitHub **Latest Release** 里的 `package.zip`。首次收录需向 `siyuan-note/bazaar` 提 PR 在 `plugins.txt` 追加一行；**之后每次更新只改 `version` 再发 Release 即可**，索引一到三小时内自动更新。
